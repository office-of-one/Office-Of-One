# Ways of Working

Set during onboarding. Changeable any time by asking.

## The five questions

1. Email drafting: [draft only / draft and send] (recommended: draft only)
2. Calendar adds: [recurring: add directly / propose] [one-offs: always confirm]
3. Invite rules: see people.md
4. Schedule:
   - Morning Memo: [weekdays or every day] at [time]
   - Evening Debrief: [time] the night before (default 8pm)
5. System of record for tasks: [chosen app, or this list]

## Set from the ecosystem sweep, not asked

- Using it for: [work / personal / both]
  Stated as an observation in Step 3. Re-ranks the question pool
  and shapes what the Morning Memo leads with.
- Timezone: [from the calendar]
  Both scheduled tasks run against this. Never guess it; if the
  calendar does not say, ask.
- Project link: [pasted by the user in Step 6]
  Used in the Friday Morning Memo so the 1:1 is one tap away. If
  it is missing, the Friday line falls back to "Open your agent in
  Claude and say let's do our 1:1."

## Not asked, never optional

- Delivery is always email plus the app. There is no choice to
  make, so onboarding does not ask.
- Both the Morning Memo and the Evening Debrief are created
  automatically. Only their times are chosen.
- Nothing else recurring is ever auto-created. Everything else is
  proposed and confirmed.
